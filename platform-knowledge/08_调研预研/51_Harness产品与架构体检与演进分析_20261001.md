## 2. 架构设计不足（六项；A-H1/A-H2 已归并在册 REQ，本档给输入细化）

| # | 不足 | 证据 | 归并/建议 |
| --- | --- | --- | --- |
| **A-H1** | **沙箱执行世界与文件原语执行世界割裂**（harness 最大架构断层）：docker.go/k8s.go 无任何 volume 挂载（实证 grep Binds/volumes 零命中）——inprocess 下文件工具直写宿主 FS，docker/k8s 沙箱内 agentd 写容器 FS，work_dir 语义随 runtime_backend 漂移；REQ-218 文件视图联动后「文件可见→文件可执行」断在沙箱档 | `runtime/docker.go`/`runtime/k8s.go` 零挂载点 | **已归并 REQ-225①（M53 触发驱动）**。输入细化：volume 绑定须同步定义 agentd 内安全根解析（容器内路径↔宿主 work_dir 映射，SafeJoin 根切换）；k8s hostPath 安全面（节点亲和/只读选项）；inprocess 档诚实标注（无隔离边界，文件工具即平台进程权限） |
| **A-H2** | **harness 治理动作无结构化审计事件**：hook 拒绝仅结构化回执回喂模型（hooks.go:54-70）无 run_event；审批仅 run.interrupted kind=approval（runner.go:639-645）；verify 仅 run.finished reason=verify_failed+run.warning 两行——轨迹面板/审计/REQ-223 评估三类消费方都靠反推 | `tool/hooks.go:54-70`；`chat/runner.go:639-645,358-378` | **已归并 REQ-224③④（M52）**。输入细化见 §3-W1 |
| **A-H3** | **工具结果落库无上限**——tool.result 的 content 全量入 run_event（`data["content"]=mo.Message.Content`，runner.go:845 实证无截断）：http_fetch 512KB/kubectl 大输出/save_file 内容单行膨胀 SQLite；context 层 4k 剪枝只管模型输入侧，存储侧零治理。REQ-224⑤ 只评估了 message.delta 落库，tool.result 的**存量膨胀**未在册 | `chat/runner.go:838-868`；REQ-202 httpfetch 512KB 截断仅到工具返回 | 建议**并入 REQ-224**（见 W1c）——轨迹/重放/评估三个消费方都在吃这张表 |
| **A-H4** | **hooks 硬编码不可扩展**——进程内 DefaultHookChain() 仅 fetchGuard（hooks.go:142-144）；无 agent 级开关、无自定义 deny 规则、无外部 hook 形态；**fetchGuard 只护 http_fetch**——连接器写操作（kubectl_apply/ssh exec）零 hook 防护，只有粗粒度审批兜底（叠加 P-H1 两档粒度问题）；cmdGuard 规则表先行无消费 | `tool/hooks.go:142-144`；REQ-214 连接器工具无 guard 包装 | cmdGuard 生效**绑定 REQ-225②**（run_command 接线验收项）；hooks 可配置化列独立观察项（W4） |
| **A-H5** | **执行期超时/重试策略编码期固定**——重试白名单仅装配期 MCP 拉取一处（assembler.go:464）；http_fetch 10s/512KB 硬编码；连接器插件调用/ssh exec/kubectl 无统一超时面，ctx 取消向插件服务的传播一致性未验证 | `chat/retry.go` 唯一装配点；`tool/httpfetch.go` 常量 | P3 观察项（W6）：先做「执行期超时统一入口」小件，可配化后置 |
| **A-H6** | **连接器运行期健康无事件化**——状态仅配置时点 test/tested_at（REQ-214 P2④ 有意取舍「持续凭据使用安全面」），运行中失效→装配降级仅 run.warning 单点；「已授权连接器本 run 实际降级」在轨迹面板混在通用警告里无专属行 | `assembler.go:457-526` 降级告警；REQ-214 P2④ 口径 | 建议 connector.degraded 结构化事件随 REQ-224 事件契约顺带（W1d） |
