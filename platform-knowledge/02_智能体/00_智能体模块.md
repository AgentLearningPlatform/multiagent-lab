# 智能体（Agent）

## 产品定位

智能体是平台的核心可复用配置实体：名称、描述、系统提示词、模型与采样参数、工具/技能/MCP 挂载、执行后端的组合。既可以**单独直聊**（一个 Agent 名下挂多个对话，折叠树管理），也可以作为成员被项目引用组成多 Agent 团队。左栏折叠树支持**跨智能体直接点选会话**（REQ-212，2026-09-30）：点击会话若归属其他智能体，选中智能体与会话原子切换、一步到位；点节点头部=选中智能体并回到空态（传统路径）。

## 设计原理

- **ReAct 循环**：每个 Agent 运行时装配为 Eino ADK 的 ChatModelAgent——模型思考 → 调用工具 → 观察结果 → 再思考，直到给出答案或到达最大迭代次数（防死循环）。
- **描述即路由语义**：多 Agent 协作时，子 Agent 的 description 是主 Agent 判断"何时委派给谁"的关键依据，所以创建时值得认真写。
- **工具合并管线**（装配期按序合并、先到先得）：①勾选的内置工具（current_time 等）→ ②技能携带的工具白名单 → ③Agent 级配置的 MCP server 工具（`{server}__{tool}` 前缀防撞）→ ④本体挂载时的 onto_* 工具（6 个：get_concept/get_instance/list_instances/neighbors/sparql_query/list_concepts——REQ-215 起指引只注入**紧凑口径**（本体身份+规模+用法），不预载概念清单，概念发现由 `list_concepts` 运行时按需拉取；对话本体 chip 支持换方案与**关闭（保留绑定）**）→ ⑤项目会话的文件工具（list_files / read_file / save_file）。
- **外部连接器（REQ-214 ✅ 已交付 2026-09-30，M46）**：agent 连接外部能力（ssh 主机/k8s 集群/外部 MCP server）统一为「连接器」产品概念——产品层只呈现连接器，MCP 挂载降为底层交付驱动之一。设置页「连接器」分区（与模型管理平级：三类型实例管理/凭据加密托管/连接测试）；侧板「能力」页签授权勾选=agent 级连接白名单；Kubernetes/SSH 连接器由平台托管自研 Go MCP 插件服务承载（backend 进程内嵌 loopback :8093，kubectl CLI 包装四工具 + x/crypto/ssh exec-per-call，非零 exit code 透传）；凭据服务端绑定（AES-256-GCM）不进 LLM 上下文不进工具参数；装配期 {连接器实例名}__{tool} 前缀改名，REQ-14 审批与 run_event 审计自动覆盖；内置 open-ontologies 连接器（oo 预设迁移）。
- **推理后端可插拔**：默认 `eino-adk`（进程内完整能力）；也可选外部 CLI 后端（Claude Code / OpenCode / Aider / DeepSeek Harness），按 PATH 探测、协议桥接，技能/MCP 降级为提示词注入。
- **记忆还原与上下文工程（REQ-201/M37）**：每轮运行把历史消息还原为多轮上下文，历史对话重开即完整续聊；工具调用轨迹由 run_event 派生保全（悬空调用补「结果未知」合成文本）、历史按 agent 级预算档（紧凑/标准/完整）治理——超限先压缩（LLM 摘要持久化）再裁剪，均以运行警告诚实标注。
- **架构坐标系**：智能体运行时可拆为十层（传输/装配/循环/状态/上下文/工具/能力 seam/多智能体/交互/可观测），本平台强在装配与事件流、弱在上下文工程与能力替换——详见 [36_智能体开发架构深度对比](36_智能体开发架构深度对比_本地实现与DeepSeekHarness.md)。
- **调用轨迹面板（REQ-217 立项，M48 待领取）**：对话窗口新增「调用轨迹」——按运行分组、可按类型/运行/关键字过滤、行点开原始入参/结果 JSON 的时间线视图（智能体/项目同构；「重放」并入面板；头部过程配置收编面板显示设置，审批开关迁侧板配置；侧板默认收缩为一竖行按钮常驻右侧、点击展开）。
