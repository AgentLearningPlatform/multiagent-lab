## 命名规范（REQ-188）

1. **目录**：`NN_名称/`——NN 两位数字决定页面顺序；顶层 01~07 对齐导航栏模块序，新增顶层目录取下一可用号（08 起）即自动成组（未带前缀的陌生目录兜底成组置尾，不丢档）。
2. **文件**：`NN_名称.md`——`_` 只作「前缀-名称」分界：
   - `00_` 保留给**模块主页**（导读/整体设计，组内置顶，页面显示「模块导读」）；
   - **全局编号档**沿用 docs/18 注册表全局号（如 07/08/13/16/17/19/21/22/23/24/25/26/27），编号不回收、不重编；
   - **本地排序档**用 **31~99 号段**（避免与全局 01~27 号段混淆），目录内插空取号；
   - 文件名**不带日期后缀**（时间线由 git 承载）；附件统一 `NN_名称.html`（页面不渲染，见特例表）。
3. **frontmatter 必带**：`module`（所属模块）、`topic`（主题一句话）、`desc`（页面副标题）、`synced`（最后同步日期）；导读页另带 `role: home` 与 `req`/`docs`/`decisions` 源指针。语义级变更按 AGENTS.md 纪律 7 同步命中导读页。

## 页面联动机制（建入即上页）

| 动作 | 页面效果 |
| --- | --- |
| 新建 `NN_名称.md` 到模块目录 | 重建后出现在该组，按 NN 排序，标题自动去 `NN_` 前缀、`_`→`·` |
| 新建 `NN_名称/` 子目录 | 重建后成为该组 L2 菜单，按 NN 排序 |
| 新建顶层 `NN_名称/` | 重建后自动成 L1 组（icon 查表，未登记用默认图标，置已登记组之后） |
| 移动/重命名带全局编号的文档 | 编号→路径映射构建期自动派生（docref），互引不断链 |

## 维护约定

1. 新增主题页：按命名规范落入模块目录，重建即生效，**无需改前端、无需回填本 README 清单**（页面即清单）。
2. 新增顶层目录：`NN_名称/` 建入即可；icon 如需定制在 `web/src/pages/ReferencePage.tsx` 的 ICONS 表补一行（可选，不补用默认）。
3. 编号不回收：迁移文档保留原编号文件名；引用统一写 `platform-knowledge/<模块>/<原文件名>` 或文内相对路径。
4. 语义级同步：需求/方案档语义变更时按 AGENTS.md 纪律 7 同步命中本目录的导读页。
