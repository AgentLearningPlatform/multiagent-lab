# 本体可视化方案调研（REQ-154 立项依据，2026-09-25）

> 任务来源：主人指出「本体可视化界面比较简单，只是二维，无法满足复杂本体的可视化展示；行业内很多开源项目已有不错方案，最好能三维或伪三维展示缩放、点击节点聚焦放大」——要求调研可选方案。
> 性质：立项前调研（research/ 单源）；结论回写 03 v0.28（REQ-154/D-O18）、02 §12 M21、18 v1.19；本档只调研比选，不含实现。
> 现状基准：React Flow（@xyflow/react v12）2D 画布——GraphEditor（966 行，概念/实例双类自定义节点，编辑态）+ SpecGraph（浏览态）；WebVOWL 嵌入在 D-O9/D-O12 收口为 P3 可选（OWL2VOWL 预转换缓存设计已留）。

## 2. 推荐基线细部（VIZ-1：3d-force-graph 三维浏览 Tab）

- **数据映射**：spec_json → `{nodes, links}`——Concept 节点（球体、按顶层类着色）/ Instance 节点（八面体、继承概念色系）/ 关系边（label 悬浮）；入口挂在资产详情「可视化」区新增「三维浏览」Tab（与 2D React Flow 并列切换）。
- **点击聚焦规范**（交互基线，全可视化视图统一）：
  1. click 节点 → 相机 fly-to 聚焦放大（`focusOnNode`）+ 直接邻居高亮、其余淡出（透明度梯度）；
  2. 侧栏滑出该节点属性（REQ-19f 范式：名称/类型/属性/出入关系计数）；
  3. 双击空白/「复位」按钮 → 回全景；搜索框定位实体并自动聚焦；
  4. 过滤器：按节点类型/关系类型显隐；标签按相机距离 LOD 显隐（防标签风暴）。
- **性能声明**：WebGL 下千级节点流畅（目标覆盖 NFR-O-3「100+ 概念」并留 10 倍余量）；万级作为 10 倍压测目标（不承诺）。
- **边界**：只读浏览——编辑永远回到 React Flow GraphEditor（REQ-71），两视图数据同源（spec_json），零同步问题。

## 3. 风险与验证

| 风险 | 缓解 |
| --- | --- |
| 3D 可读性（边穿越/遮挡/找不到节点） | 雾化深度提示 + 标签 LOD + 邻居聚焦模式（默认收束视野）；伪 3D `force-graph` 作对照选项 |
| Safari/部分 WebGL 驱动兼容 | 仅只读视图受影响；降级入口保留 2D React Flow |
| 大图性能 | 分页/子图装载（按顶层类切片）；万级压测入 10 倍目标 |
| G6 5 成熟度未知 | VIZ-4 为 PoC 而非承诺；PoC 结论回写 15 号 |
