## 1. 定位与学习目标

| 项 | 内容 |
| --- | --- |
| 模块定位 | 知识库是主平台内的**全局资源**（非外部服务）：库列表/库详情两栏视图，文档入库→切分→向量化→检索→对话注入的完整闭环。 |
| 学习目标 | **LG-11（承接 01）**：掌握 RAG 最小闭环——文档加载/切分/Embedding/检索/上下文注入；v0.6 起基于开源组件搭建而非自研。 |
| 实现基调 | 开源优先（Q-18 已定）：向量存储与检索优先使用开源组件；自研仅保留 SQLite fallback 作学习对照。选型结论与对比分析见 12《知识库_方案设计.md》§5。 |
| 边界 | 简单 RAG：不做 PDF/OCR/表格抽取、Rerank/混合检索、GraphRAG 等进阶能力（需求池见 §4）；对话侧如何选择与引用知识库见 01（REQ-19a/19b/17/56）。 |

## 5. 场景与验收

| 场景 | 验收标准（承接 01 验收第 2/6 条口径） |
| --- | --- |
| SC-6 建库并引用 | 新建知识库 → 导入文本 → 完成切分向量化（开源向量组件）；对话选择该知识库提问，回答引用召回片段与来源；检索试运行可见片段与得分 |
| 组件切换验收 | SQLite fallback 与 Qdrant 路径下，同一知识库的检索试运行结果一致（TopK/阈值相同口径）；Store 切换仅改配置 |
| SC-K1 依赖问答（v0.6） | 技术文档 graphrag 库问「A 依赖哪些组件」——经关系遍历给出完整依赖列表（多跳=2 可命中经中间实体的链路），claims 点击定位原文 | REQ-128，M16 一 |
| SC-K2 因果溯源（v0.6） | 故障案例库问「为什么出现 X」——答案中的结论带 claim 溯源，点击高亮原文片段 | REQ-128，M16 一 |
| SC-K3 关系网络梳理（v0.6） | 会议纪要/笔记导入后，图谱页搜索某人物/系统，展开其协作与依赖网络 | REQ-127，M16 一 |
| SC-K4 全局主题问答（v0.6） | 问「这个知识库整体在讲什么」——命中社区摘要并给出成员实体（local 与 global 两种检索并存） | REQ-130，M16 二 |
| SC-K5 检索对照学习（v0.6） | 同一问题分别用 RAG 库与 GraphRAG 库回答（复用对话对比模式 REQ-19e），对照召回差异——检索策略教学的核心场景 | REQ-107 + 19e，可演示 |
