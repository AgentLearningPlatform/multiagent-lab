# 医学常识（家庭常见病）本体 · 建模说明

> 示例本体建模说明（REQ-153 ①，第 6 示例）。seed-learning key=med_common 一键灌装。自建教学本体，全部内容取自公开医学常识，不复制任何受授权保护的数据库内容（HPO/ICD 仅作分类结构参考，见 15 号登记簿）。

## 背景与目标

提供**百级概念**规模的种子本体（102 概念 / 170 实例），兼顾三件事：①学习「分类树在概念层、知识网在实例层」的两层建模分工；②作为 NFR-O-3「浏览 100+ 概念不卡死」与验收 23 后半/24（百级本体浏览与查询流畅）的性能验证载体；③给 sparql_query（REQ-151）提供 4 固定工具答不了的开放问题素材（如「哪些药物禁忌于胃溃疡」）。

领域选择家庭常见病：症状/疾病/药物/检查四类目 + 禁忌关系网，人人可校验真伪，适合作为教学与演示底座。

## 目标 CQ 列表（能力问题）

1. 流行性感冒常表现为哪些症状？需与什么病鉴别？（表现为 + 需鉴别）
2. 哪些药物禁忌于胃溃疡？（禁忌于——禁忌关系网核心问题，SPARQL 直接三元组命中）
3. 高血压可能并发哪些疾病？（并发）
4. 确诊胃癌需要做哪些检查？（典型检查）
5. 美托洛尔为什么不能给哮喘患者开？（禁忌于 + 概念层分类树联合回答）
6. 有多少概念属于「疾病」下的「感染性疾病」分支？（subClassOf 层级计数，纯概念层查询）

## 建模决策记录

| 决策 | 理由 |
| --- | --- |
| 分类树放概念层（102 类目，2~4 层），具体病种/症状/药物/检查放实例层 | spec 的实例关系断言只能「实例→实例」：把「阿司匹林 禁忌于 胃溃疡」这类知识对落在实例层才能被 SPARQL 三元组直接命中；概念层保持纯分类（对照 SNOMed/ICD「疾病即类目」的做法，本例做了教学化取舍） |
| 实例类型挂**最近分类**（如 流行性感冒→呼吸道传染性疾病） | 无推理引擎（Oxigraph）时 rdf:type 直查即可按分支聚合；查上层类目用 `rdf:type/rdfs:subClassOf*` 属性路径——这是 sparql_query 的教学点（对照 Fuseki 推理方案 O6） |
| 药物实例同时带「治疗/缓解/禁忌于/可引起」四类断言 | 禁忌关系网（REQ-153 点名）由实例层承载；「美托洛尔-禁忌于-支气管哮喘」等断言本身即用药常识教学素材 |
| 相互作用（华法林×阿司匹林、氯吡格雷×奥美拉唑、地高辛×呋塞米）选经典药对 | 全部为公开常识级的经典相互作用，教学辨识度高 |
| 检查项目挂分类实例（血常规→血液检查） | 让「疾病→典型检查→检查项目」链路二跳可查 |

## 局限与反例

- **类型级断言无处安放**：「流感 表现为 发热」在本体里是实例对断言（个案知识），不是类级公理——若想要类级语义（任何流感都表现为发热）需要 OWL 公理层，超出 spec_json 表达范围。
- **无时间与程度维度**：「发热 38.9℃ 持续 3 天」装不下——症状的量化需要事件化建模（对照 orgs.README 的 n-ary 反例）。
- **药物只有类目树**：物质（对乙酰氨基酚）与制剂（对乙酰氨基酚片）未区分，也未建剂量/途径——真实药物本体（如 DrugBank/RxNorm）的核心复杂度被刻意省略。
- **剂量均以常识为准，不构成用药建议**：本体内容为教学用公开常识，不能替代医嘱。
