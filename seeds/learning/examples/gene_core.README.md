# 基因与中心法则本体 · 建模说明

> 示例本体建模说明（REQ-153 ②，第 7 示例）。seed-learning key=gene_core 一键灌装。自建教学本体：基因/蛋白符号命名对齐 HGNC（genenames.org），三大功能类目树结构参考 Gene Ontology 三轴（生物过程/分子功能/细胞组分），字段均为公开常识级内容、不复制数据库记录（见 15 号登记簿）。

## 背景与目标

提供第二个**百级概念**规模种子（104 概念 / 94 实例），与医学常识本体（med_common）互补：①演示**五实体类目树**（基因/转录本/蛋白质/通路/染色体位置）+ **三大功能类目树**（GO 风格）的多根分类结构——Graph3D 按根着色后呈六七个色系岛屿，是可视化演示的最佳载体；②以**中心法则链**（基因—转录为→转录本—翻译为→蛋白质）展示关系链建模；③作为 NFR-O-3/验收 23 后半/24 的第二个性能验证载体。

## 目标 CQ 列表（能力问题）

1. TP53 转录出哪些转录本？翻译成什么蛋白？（转录为 + 翻译为——中心法则两跳）
2. 哪些基因参与 MAPK 信号通路？（参与通路）
3. BRCA1 定位于染色体什么位置？7 号染色体上有哪些基因？（定位于——按带聚合）
4. p53 蛋白与谁存在蛋白相互作用？（相互作用——PPI）
5. 抑癌基因和原癌基因各有哪些？谁调控谁？（概念分支计数 + 调控）
6. EGFR 和 ACTB（β肌动蛋白）有什么共同点？（同定位于 7p11.2——共定位教学点）

## 建模决策记录

| 决策 | 理由 |
| --- | --- |
| 基因/转录本/蛋白/通路/染色体带均为「类目在概念层 + 个体在实例层」 | 基因（TP53）、转录本（TP53-201）、通路（MAPK信号通路）、细胞遗传学带（17p13.1）天然是个体——与 HGNC/Ensembl/RefSeq 的命名习惯一致，实例层断言（转录为/翻译为/定位于）有天然主语 |
| GO 三大功能类目树保留在概念层，注释以**实例属性**承载（如 p53蛋白 属性「分子功能: DNA结合」） | spec 实例关系只能连实例，而 GO 词表术语是类目；若为每个 GO 术语造实例会造成类目/个体双重身份污染。属性承载保留注释信息且详情侧栏可见，代价是无法按 GO 术语做三元组聚合（见局限） |
| 参与过程/行使功能/定位于组分三条关系只保留 schema（定义域/值域），无实例断言 | 同上——保留 domain/range 设计意图供学习 GO 注释语义，断言空缺是**有意且已文档化**的（sparql_query 查这三条返回空表是正确行为） |
| 调控/相互作用选教科书级例子（TP53→CDKN1A、MDM2×p53、MYC→CCND1） | 教学辨识度优先于覆盖度；正负调控方向靠实例属性与定义说明 |
| 基因符号全大写 HGNC 风格（TP53），转录本 Ensembl/RefSeq 风格（TP53-201 / NM_000546） | 命名对齐 REQ-153 要求；属性里保留 RefSeq 号作溯源样式示范 |

## 局限与反例

- **GO 注释不能按术语聚合**：「哪些基因参与 DNA 修复」无法用三元组命中（注释在属性里）——真实做法需 GO 术语实例化或 OWL 推理，本例刻意省略以守住「类目/个体分离」。
- **通路是黑盒节点**：通路内部级联（Ras→Raf→MEK→ERK 逐棒）未建模，通路仅作为参与关系的终点——对比 Reactome 的反应级建模是很好的进阶讨论题。
- **染色体带无区间坐标**：17p13.1 没有 bp 起止（1,561,427~1,563,394 之类），位置只有细胞遗传学分辨率——需要精确坐标时应换 GRCh38 区间属性并学习 UCSC/Ensembl 数据结构。
- **调控无方向极性**：MDM2 对 TP53 是负调控，TP53 对 CDKN1A 是正调控，当前都断言为「调控」——真实本体需区分 activates/inhibits 两条属性。
